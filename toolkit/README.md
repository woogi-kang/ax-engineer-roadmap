# 실무 템플릿

템플릿은 빈칸을 채우기 위한 문서가 아니다. 업무를 바꿀 때 빠뜨리기 쉬운 판단, 책임, 검증 결과를 확인하는 데 사용한다.

## 사용 원칙

후보를 비교할 때는 평가표에 비용 범위를 적고 실험 카드에서 검수를 통과한 완료 업무당 비용을 계산한다. 근거 기록에는 발표일과 실제 관측기간을 나눠 적는다. 실행 규칙은 승인 대기, 권한 회수, 취소 요청과 실제 중단을 구분해 기록하는 데 사용한다.

- 업무 위험과 규모에 맞게 줄여 쓴다.
- 확인하지 못한 사실은 `UNKNOWN`으로 둔다. 계획에 필요한 추정값은 가정·계산 근거와 함께 따로 표시하고 실측값과 섞지 않는다.
- 같은 정보를 여러 문서에 복사하기보다 원본 링크로 참조한다.
- 승인과 책임을 “사람”이라고만 적지 않고 역할이나 담당자를 구체적으로 지정한다.
- 결과가 기대와 다르면 템플릿보다 실제 결정 기록을 우선한다.
