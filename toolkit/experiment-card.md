## 완료 업무당 비용

같은 기간과 업무 범위에서 아래 비용을 합산한다. 추정값과 실제 지출을 구분한다. 일회성 구축비는 배분 기간과 계산 방법을 적는다.

| 비용 항목 | 금액 또는 시간 | 단가·배분 근거 | 추정/실측 |
|---|---:|---|---|
| 모델·도구 사용, 실패·재시도 포함 |  |  |  |
| 검수·수정·재작업 |  |  |  |
| 장애 대응·수동 처리·운영 |  |  |  |
| 라이선스·인프라·구축비의 해당 기간 배분액 |  |  |  |

`완료 업무당 비용 = 해당 기간의 총비용 / 검수를 통과한 중복 없는 완료 업무 수`

모델이 완료했다고 답한 횟수는 분모로 쓰지 않는다. 원본 시스템의 결과와 담당자 검수로 완료 여부를 확인한다. 완료 업무가 0건이면 단위 비용을 `N/A`(산출 불가)로 표시하고 총지출과 실패 비용은 남긴다. 기존 수동 절차도 같은 범위로 계산한다. 처리 시간 절감과 매출 효과는 별도로 측정한다.
