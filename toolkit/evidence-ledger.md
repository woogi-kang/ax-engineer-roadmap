| E-001 |  |  |  |  |  | active |

주장마다 다음 정보를 함께 남긴다. 모르는 값은 추정하지 않고 `unknown`으로 적는다.

| 항목 | 기록할 내용 |
|---|---|
| 발표일 | 원문에 적힌 공개일. 검색 결과의 수집일과 구분 |
| 관측기간 | 실제 조사·실험·운영 결과가 나온 기간 |
| 확인일과 접근 상태 | 원문을 읽은 날, 접근 가능·종료·차단·미확인 여부 |
| 표본과 분모 | 응답자·조직·업무 건수, 모집 방식과 제외 기준 |
| 측정 방법 | 자기보고, 로그, 대조 실험 등. 측정 방법이 없으면 그 사실 기록 |
| 성과 검증 | 자체 발표, 독립 자료의 교차 확인, 독립 평가를 구분 |
| 이전 주장과의 관계 | 새 변화, 뒤늦게 공개된 과거 관측, 기존 누락, 정정, 과거 상태 보존 |
| 반영 위치 | 바뀌는 문서·실습·통과 기준과 그대로 둘 내용 |

최근 발표라도 관측기간이 이전이면 그 기간의 결과로 설명한다. 종료된 채용 공고는 당시 역할을 설명하는 자료로 남길 수 있지만 현재 채용 수요로 세지 않는다. 원문을 보존할 수 있다면 허용된 저장 위치와 해시를 기록한다. 원문 전체를 저장할 권한이 없으면 URL과 읽은 범위만 남긴다.

상태:

- `active`: 현재 사용
- `needs_review`: 다시 확인 필요
- `superseded`: 새 근거로 대체
- `rejected`: 근거 부족 또는 반증
