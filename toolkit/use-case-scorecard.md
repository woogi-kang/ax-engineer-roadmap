# AX 업무 후보 평가표

## 평가 방법

각 항목을 `1~5점`으로 평가한다. 총점만으로 결정하지 않고 위험·데이터·복구 가능성 중 하나라도 기준에 미달하면 보류한다.

| 항목 | 1점 | 3점 | 5점 | 가중치 |
|---|---|---|---|---:|
| 업무 가치 | 편의 개선 | 팀 생산성·품질 | 핵심 비용·매출·위험 | 3 |
| 빈도 | 드물다 | 주·월 단위 | 매일·상시 | 2 |
| 문제 근거 | 의견만 있음 | 일부 기록 | 기준선과 반복 근거 | 3 |
| 데이터 준비 | 접근 경로·정의 불명확 | 일부 정리 필요 | 소유자·계약·접근 확인 | 3 |
| 평가 가능성 | 판정 어려움 | 담당자 검토 가능 | 반복 평가 세트 가능 | 3 |
| 복구 가능성 | 되돌리기 어려움 | 수동 보정 가능 | 즉시 중단·복구 가능 | 3 |
| 통합 난이도 | 핵심 시스템 변경 | 일부 시스템 연동 필요 | 읽기·제안부터 시작 가능 | 2 |
| 실제 업무 적용 준비 | 책임자 없음 | 일부 사용자 참여 | 책임자·사용자·운영자 확인 | 3 |
| 재사용 가능성 | 일회성 | 유사 업무 존재 | 여러 업무의 공통 패턴 | 1 |

## 비용과 업무 결과

후보별로 같은 기간의 업무 건수와 비용 범위를 적는다. 모델 비용 외에 검수·재작업·장애 대응·라이선스·통합 비용을 포함한다. 일회성 구축비는 기간별 배분 근거를 남긴다. 현재 자료로 계산할 수 없는 항목은 추정 여부와 확인할 담당자를 적는다.

| 후보 | 검수 통과 완료 업무 수 | 총비용 | 완료 업무당 비용 | 수동 절차 기준선 | 모르는 항목·확인 담당자 |
|---|---:|---:|---:|---|---|
| A |  |  |  |  |  |
| B |  |  |  |  |  |
| C |  |  |  |  |  |

완료 업무 수는 중복을 제외하고 원본 시스템과 검수 결과로 확인한다. 실패와 재시도의 비용은 총비용에 포함한다. 완료가 0건이면 단위 비용을 계산하지 않는다. 계산식과 변경 전후 비교는 [실험 카드](experiment-card.md)에 기록한다.

## 필수 통과 조건

- [ ] 업무 책임자와 사용자가 확인됐다.
- [ ] 현재 상태를 측정하거나 관찰할 수 있다.
- [ ] 데이터 소유자와 접근 경로가 있다.
- [ ] 초기 범위에서 위험한 실행을 제외할 수 있다.
- [ ] 실패를 탐지하고 수동으로 처리할 수 있다.
- [ ] 검수자와 운영자를 정했고 수정·재작업 부담을 측정할 수 있다.
- [ ] 비용 한도와 품질·권한·복구의 중단 조건을 합의했다.
- [ ] 2~4주 안에 작은 범위로 처음부터 끝까지 동작하는 기능을 만들 수 있다.
