# 업무 실행 규칙

AI가 업무에 참여할 때 지켜야 할 입력·출력·평가·권한·승인·기록·복구 규칙을 정리한다. 데이터 계약이나 API 계약을 대신하는 문서가 아니라, 한 업무의 실행 조건을 함께 확인하기 위한 템플릿이다.

각 항목에 계획만 적었는지, 샌드박스에서 시험했는지, 실제 운영에서 확인했는지를 함께 표시한다. 아직 실행하지 않은 시험에는 결과를 채우지 않는다. 상태·권한·복구 기준은 [실행 규칙과 통제](../delivery-lifecycle/05-execution-contracts.md)를 따른다.
