# Security Policy

## Supported scope

The latest GitHub Release and the `main` branch receive security fixes. When an important issue affects an older release, the project records the affected range in documentation and release notes, but it cannot guarantee a separate patch release for every historical version.

## Private reporting

Do not post vulnerabilities, proof-of-concept code, personal data, tokens, or secrets in a public issue. Report the following through a [private GitHub security advisory](https://github.com/woogi-kang/ax-engineer-roadmap/security/advisories/new):

- vulnerabilities in the site code or dependencies;
- supply-chain risks in GitHub Actions or deployment;
- instructions that could expose credentials, personal information, or workflow data when followed;
- confidential information accidentally committed to the repository.

Use a [Source update issue](https://github.com/woogi-kang/ax-engineer-roadmap/issues/new?template=source-update.yml) for factual errors, stale sources, and broken links. Follow the [Code of Conduct](CODE_OF_CONDUCT.md) for conduct reports.

Include the impact, reproduction conditions, affected version or commit, and possible mitigation when available. Use a minimal synthetic reproduction, never real personal or organizational data.

## Response targets

The maintainer aims to meet the following targets. They are not a service-level agreement or legal guarantee for this single-maintainer project.

- acknowledge and identify the next checks within 7 days;
- share an impact assessment, mitigation plan, or investigation status within 14 days;
- coordinate disclosure timing and wording with the reporter;
- publish affected versions and mitigation, and a CVE or GitHub Security Advisory when appropriate.

## Good-faith research

The project will not pursue legal action against good-faith research that follows this policy, avoids harm to people, services, and third-party systems, and accesses no more data than necessary. Keep findings private until a fix is disclosed, and obtain separate permission from the owner before testing any external system.
