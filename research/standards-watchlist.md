# 표준과 제안의 검토 목록

확인일: `2026-10-26`

이 목록은 향후 명세나 제품 지원을 다시 확인할 항목이다. 아래 계획 문서를 읽었다는 사실을 개별 제안의 채택이나 제품 지원 확인으로 바꾸지 않는다. 학습자는 현재 지원되는 방식으로 실습할 수 있으며 제안 채택을 기다릴 필요는 없다.

## 확인한 계획

| 항목 | 원문에서 확인한 범위 | 로드맵에서 다시 판단할 질문 |
|---|---|---|
| 에이전트 신원과 위임 | MCP의 2026-08-22 계획은 에이전트 신원, 더 좁은 권한의 위임과 기존 인증 표준의 연결을 후속 과제로 다룸 | 호출 주체·소유자·위임 범위·회수 기록을 어떤 명세와 제품 조합으로 검증할 수 있는가? |
| 도구 발견과 결과 형식 | 같은 계획은 점진적 도구 발견과 결과 표현 개선을 제시 | 도구가 많아졌을 때 선택 오류와 컨텍스트 비용이 실제로 줄어드는가? |
| 장기 작업과 이벤트 | 같은 계획은 Tasks와 이벤트 등 실행 요소가 함께 동작하는 방식을 보강할 예정이라고 설명 | 기존 상태 조회·재접속·중복 방지 실습에서 무엇을 바꿔야 하는가? |
| Skills 운영 절차 | 2026-10-22 AAIF 기증 발표는 버전별 릴리스, 제안 절차와 보안 지침을 향후 계획으로 제시 | 배포·설치 검토·호환성·폐기 절차 중 새로 확인할 것은 무엇인가? |

출처: [MCP 계획, 2026-08-22](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/), [Agent Skills 기증 발표, 2026-10-22](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation). 두 원문은 2026-10-26에 확인했다. 개별 제안의 최신 채택 상태와 모든 제품의 지원 여부를 조사한 목록은 아니다.

DPoP나 토큰 교환 같은 기존 표준, 공급자가 이미 제공하는 신원 기능, MCP가 공통으로 정하려는 연결 방식은 구분한다. 현재 MCP 기준과 선택 확장은 [도구 호출과 MCP](../technical-foundations/tools-and-mcp.md)를 따른다. Skills의 현재 파일 형식은 [Agent Skills 명세](https://agentskills.io/specification)를 확인한다. 이 목록은 기존 권한·평가·복구 기준을 완화하지 않는다.

## 정식 학습 기준에 반영할 조건

다음 표는 이 저장소의 편집 기준이다. 외부 표준이 요구하는 필드가 아니다.

| 확인 항목 | 남길 기록 |
|---|---|
| 문서 상태 | 제안·초안·선택 확장·정식 명세·폐기 예정 중 어디에 해당하는지와 그 근거 |
| 실제 지원 | 시험한 Host·Server·SDK·제품 버전, 설정과 확인일 |
| 업무 영향 | 바뀌는 입력·출력·권한·상태·비용과 영향을 받지 않는 범위 |
| 검증 | 이전 방식과 같은 입력·초기 상태로 비교한 결과, 실패·권한 회수·중복·복구 기록 |
| 전환과 복구 | 호환 기간, 복구할 버전, 담당자, 기존 방식의 유지·폐기 결정 |

명세가 정식이어도 사용하는 제품에서 지원하지 않으면 현재 실습의 필수 조건으로 넣지 않는다. 베타나 제안은 선택 실험으로 표시한다. 단순히 새 기능이 생겼다는 이유로 기존 통과 기준이나 평가 결과를 지우지 않는다.

## 다시 확인할 때

공식 릴리스나 폐기 공지가 나오거나, 사용하는 제품·SDK가 바뀌거나, 기존 방식으로 해결하지 못한 문제가 생기면 해당 항목을 검토한다. 원문에 접근하지 못하면 미확인 상태로 남기고 마지막으로 읽은 날짜를 유지한다.

| 검토일 | 항목·원문·버전 | 이전 상태 | 확인한 변경 | 유지·실험·정식 반영·보류 | 영향 문서·평가 기록 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

확인한 근거는 [근거 기록](../toolkit/evidence-ledger.md)에, 변경 전후 비교는 [실험 카드](../toolkit/experiment-card.md)에 남긴다.
