# AX·인접 직무 공고 기록

확인일: **2026-10-26**(J001–J027) · **2026-10-27**(J028–J039) · 최근 게시일 비교 기준: **2026-08-01**

직무 본문을 읽은 **공고 기록 39개**다. 회사의 원 공고 ID가 연결되지 않은 채널은 별도 기록으로 두므로 고유 채용 건수나 신규 일자리 수가 아니다. `added_at`은 이 레지스트리에 넣은 날짜이며 인터넷에 처음 올라온 날이 아니다.

- 모집 표시 확인 19개 · 마감 표시 확인 12개 · 미확인 8개
- 주 출처 기준 기업·기관 공식/ATS 15개 · 채용 플랫폼 24개
- 게시일이 비교 기간에 속하는 원문: GM 1개. 나머지 38개는 게시일 미상.

공고 상태와 원문 접근 상태는 다르다. 지원 링크나 모집 표시가 있어도 지원 제출 성공을 뜻하지 않는다. 마감 표시가 있으면 미래 마감일이나 상시채용 문구보다 우선한다. 확인일은 도구가 반환한 자료를 읽은 날이며 실시간 상태를 보장하지 않는다.

## 읽는 방법

- 직함보다 실제 대상 업무와 구현·운영·지원 책임을 비교한다. 내부 AX, 고객 딜리버리, pre-sales와 혼합 역할을 구분했다.
- J028부터는 직함에 AX가 없어도 업무가 겹치는 AI Agent 엔지니어와 FDE(Forward Deployed Engineer) 공고를 함께 기록했다. 본문으로 대상 업무를 판단하지 못한 공고는 역할 범위를 미분류로 둔다.
- 필수·제시 요건과 우대는 핵심 요약이다. 인재 프로필 형식의 공고는 정식 필수·우대 구분이 없다는 한계를 함께 적었다. 우대 미확인은 우대 조건이 없다는 뜻이 아니다.
- 실습 연결은 이 로드맵의 편집 제안이다. 해당 회사가 실습을 인정하거나 채용을 보장한다는 뜻이 아니다.
- ID 대응이 확인되지 않은 관련 자료는 `related_sources`로 분리하고 이 공고의 상태 집계에서 제외했다.
