# 리서치

이 디렉터리는 로드맵의 역할 정의, 구조, 공개 사례를 뒷받침하는 외부 근거를 기록한다. 직접 실행한 실습과 외부 조직이 발표한 사례를 섞지 않는다.

## 문서

- [공개 AX 사례 카탈로그](public-ax-cases.md): 국내 10개, 해외 15개 사례의 업무 흐름, 사람의 판단 지점, 공개 결과와 근거 한계를 비교한다.
- [공개 사례 적용 맵](public-case-application-map.md): 25개 공개 사례에서 추출한 패턴이 기존 10개와 신규 5개 실습에 어떻게 연결되는지 추적한다.
- [AX Engineer 공개 역할 검토](ax-engineer-role-review.md): 현재 채용·현장 자료에서 반복되는 책임을 정리한다.
- [개발자·AI Agent 로드맵 검토](roadmap-benchmark-review.md): 기존 로드맵에서 참고한 구조와 AX 관점에서 추가한 내용을 설명한다.
- [출처 정책](source-policy.md): 사실, 공개 연구, 현장 근거, 가설을 구분하는 기준이다.

## 읽는 방법

- `case-studies/`는 이 저장소에서 직접 실행하거나 실습하도록 설계한 사례다.
- 이 디렉터리의 공개 사례는 외부 조직의 공식 발표와 고객 사례를 구조화한 참고 자료다.
- 기업이나 공급자가 발표한 성과 수치는 측정 방법과 원자료가 공개되지 않으면 독립 검증된 결과로 취급하지 않는다.
- 공개 사례에서 아이디어를 가져오더라도 데이터, 승인, 권한, 평가, 중단, 복구 조건은 새 조직의 환경에서 다시 정해야 한다.
