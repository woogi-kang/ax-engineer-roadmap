# 리서치

이 디렉터리는 로드맵의 역할 정의, 구조, 공개 사례를 뒷받침하는 외부 근거를 기록한다. 직접 실행한 실습과 외부 조직이 발표한 사례를 섞지 않는다.

## 문서

- [공개 AX 사례 카탈로그](public-ax-cases.md): 국내 16개, 해외 24개 업무 사례의 흐름, 사람의 판단 지점, 공개 결과와 근거 한계를 비교한다.
- [채용 공고 기록](hiring-signals.md): 공고 기록 39개의 책임·요건·모집 표시와 확인일을 정리한다. 중복 가능성이 있어 고유 채용 건수와는 다르다.
- [2026-10-26 자료 갱신 기록](evidence-refresh-2026-10-26.md): 조사 범위, 추가·정정한 내용, 접근 실패와 보류 자료를 확인할 수 있다.
- [공개 사례-실습 연결표](public-case-application-map.md): 기존 25개 사례의 반영 위치와 추가 15개 사례에서 실습에 참고할 질문을 보여 준다.
- [AX Engineer 공개 역할 검토](ax-engineer-role-review.md): 2026-07-23 기준 자료와 2026-10-26에 확인한 역할·교육 근거를 구분하고 내부 AX와 인접 직무의 책임을 비교한다.
- [개발자·AI Agent 로드맵 검토](roadmap-benchmark-review.md): 기존 로드맵에서 참고한 구조와 AX 관점에서 추가한 내용을 설명한다.
- [운영과 현업 적용의 근거 검토](operating-evidence-review.md): 비용, 정책 준수, 역할별 검수에 반영한 조직 조사의 발표일·관측기간·표본과 한계다.
- [출처 정책](source-policy.md): 사실, 공개 연구, 현장 근거, 가설을 구분하는 기준이다.
- [표준과 제안의 검토 목록](standards-watchlist.md): 계획 문서의 상태와 실제 제품 지원을 구분하고, 정식 학습 기준에 반영하기 전에 확인할 조건을 적는다.

## 읽는 방법

- `case-studies/`는 이 저장소에서 직접 실행하거나 실습하도록 설계한 사례다.
- 이 디렉터리의 공개 사례는 외부 조직의 공식 발표와 고객 사례를 구조화한 참고 자료다.
- 기업이나 공급자가 발표한 성과 수치는 측정 방법과 원자료가 공개되지 않으면 독립 검증된 결과로 취급하지 않는다.
- 공개 사례에서 아이디어를 가져오더라도 데이터, 승인, 권한, 평가, 중단, 복구 조건은 새 조직의 환경에서 다시 정해야 한다.

## 이번 근거 갱신의 범위

2026-10-26에 기존 공개 사례 25개 모두의 원문 확인을 시도했다. 24개는 주요 본문을 읽었고, K06 포스코는 접근 실패로 과거 기록을 유지했다. 업무 사례 15개를 추가해 현재 40개이며, 기존 원문 26개를 포함한 고유 URL 54개를 [사례 레지스트리](public-ax-cases.json)에서 관리한다.

채용 기록은 모집 표시 확인 11개, 마감 표시 확인 8개, 미확인 8개다. 게시일이 2026-08-01 이후임을 확인한 공고는 GM 1개이며 나머지 26개는 게시일 미상이다. 확인일을 게시일로 대신하거나 이 표본으로 시장의 증감을 추정하지 않는다.

관측기간·표본·방법이 빠진 기업 수치는 자체 발표로 표시한다. 후속 근거가 생겨도 실행 가능한 공개 시뮬레이션 1개와 실행 전 설계 14개의 근거 단계는 달라지지 않는다.
