# AX 기술 기반

이 디렉터리는 AI Agent를 만드는 기술 목록이 아니라, 업무 시스템을 안전하게 배포·운영하기 위해 AX Builder가 판단할 기술 기반을 다룬다.

## 먼저 적용할 원칙

복잡한 구조가 더 높은 숙련도를 뜻하지 않는다.

```text
결정적 규칙
→ 검색·분류
→ 초안·제안
→ 사람 승인 후 실행
→ 범위가 제한된 자동 실행
→ 필요한 경우에만 Agent Loop
```

더 단순한 방식이 성공 기준을 충족하면 그 방식을 유지한다. 모델·프레임워크·클라우드 이름은 현재 구현 선택지일 뿐 핵심 역량이 아니다.

## 학습 깊이

- **비개발 실무자**: 각 영역의 위험과 승인 경계를 설명한다.
- **AX Builder**: 직접 구현하고 시험하며 운영 증거를 남긴다.
- **리더·거버넌스**: 투자·책임·공급자·중단 결정에 필요한 질문을 한다.
- **데이터·보안·운영**: 데이터 사용, 접근 권한, 관측, 사고 대응 기준을 공동 설계한다.

## 기술 노드 완료 조건

각 문서는 같은 질문을 따른다.

```text
왜 필요한가
무엇을 알아야 하는가
어떤 조건에서 무엇을 선택하는가
무엇을 직접 해볼 것인가
어떤 증거를 남길 것인가
어떤 실패를 피할 것인가
누구와 합의할 것인가
어떤 출처를 확인했는가
```

읽기만으로 완료하지 않는다. [실습 프로젝트](../projects/README.md)에서 업무 제약과 실패를 재현한다.
