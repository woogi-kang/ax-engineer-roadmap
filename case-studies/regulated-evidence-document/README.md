# 사례: 근거 자료에서 출처가 연결된 규제 문서 초안까지

<!-- case-boundary:start -->
## 현재 범위와 설계 목표

| 구분 | 쓰기 영향 | 자율성 | P 단계 |
|---|---|---|---|
| 현재 공개 실행물 | 외부 쓰기 없음 | A0 | 없음 |
| 설계 목표 | 초안 전용 | A1-A2 | P1, P2, P3 |

현재 값은 이 저장소에서 재현할 수 있는 범위만 나타낸다. 설계 목표는 아직 구현 범위나 조직 운영 성과가 아니다.
<!-- case-boundary:end -->

합성 계약·연구·제품 자료를 읽고 사실과 가정을 구분해 문장별 출처가 있는 규제 문서 초안을 만드는 시뮬레이션이다. 법률 자문, 규제 제출, 임상·제품 결정을 대신하지 않는다.

## 현재 실행물과 근거

현재 근거는 `simulation-design` 문서다. [공개 사례 G09·G14](../../research/public-case-application-map.md)에서 계약·소송 문서 인용, 사실·가정 분리, 분야별 검토와 버전 영향 추적이라는 질문을 가져왔다. 실제 고객·사건·임상 자료는 사용하지 않았다.

## 1. 사례 성격

| 항목 | 내용 |
|---|---|
| 도메인·산업 | 데이터·운영 / 법무·생명과학 |
| 위험·설계 목표 자율성 | 높음 / A1–A2 |
| 설계 목표 연습 범위 | P1–P3, 문서 초안 전용 |
| 합성 입력 | 계약 8건, 연구 요약 6건, 제품 가정·상충 자료, 폐기된 문서 버전 |

## 2. 문제와 책임

전문가는 많은 자료에서 조항·사실·가정·누락을 찾아 정해진 양식으로 합친다. 문장 하나의 출처나 관할·버전이 잘못되면 법률·규제 판단을 왜곡할 수 있다. 분야별 소유자가 자기 섹션을 승인하고 지정 책임자만 최종 문서를 확정한다.

## 3. 목표 흐름

```text
합성 근거 패킷 수신
→ 문서 권한·버전·관할·유효 상태 확인
→ 사실, 인용, 가정, 충돌, 누락 추출
→ 템플릿·규칙 버전 선택
→ 문장별 출처와 불확실성이 있는 초안
→ 법무·임상·제품 등 분야별 검토
→ 충돌 해소와 승인 버전 고정
→ 초안과 감사 기록만 문서 샌드박스에 저장
```

## 4. 데이터와 통제

| 원본 | 필요한 상태 | 통제 |
|---|---|---|
| 문서 보관소 | 문서 ID, 버전, 권한, 유효 상태 | 폐기·권한 없는 문서를 제외한다. |
| 인용 인덱스 | 페이지·문단·표·원문 해시 | 모든 중요 문장을 원문 위치와 연결한다. |
| 템플릿·규칙 | 관할, 문서 유형, 시행일 | 잘못된 관할·버전을 적용하지 않는다. |
| 승인 원장 | 섹션, 버전, 승인자, 변경 | 한 섹션 변경이 기존 승인을 무효화한다. |

## 5. 승인·중단 경계

- AI는 추출, 비교, 인용과 초안만 수행한다.
- 출처 없는 결론, 사실처럼 표현한 가정, 해소되지 않은 충돌은 승인 가능 상태가 아니다.
- 법률 해석, 안전성·유효성 판단, 제출 전략과 최종 서명은 분야 책임자가 맡는다.
- 외부 제출·발송·전자서명은 범위에서 제외한다.
- 문서 권한이나 기밀 등급을 확인하지 못하면 해당 자료를 읽지 않는다.

## 6. P1–P3와 평가

| 단계 | 실습 | 통과 기준 |
|---|---|---|
| P1 | 합성 자료에서 사실·가정·충돌과 인용 추출 | 중요 문장 출처 100%, 폐기 버전 인용 0건 |
| P2 | 분야별 수정·승인·거절 | 미해소 충돌 승인 0건, 변경 뒤 재승인 |
| P3 | 승인 초안과 감사 기록을 샌드박스에 저장 | 승인 버전과 저장 버전 일치, 중복·부분 실패 복구 |

생성 분량보다 인용 정확성, 사실·가정 혼동, 누락·충돌 탐지, 분야별 수정량, 승인 무효화와 감사 재현 시간을 측정한다.

## 7. 실패 주입과 복구

| 실패 | 기대 동작 | 복구 |
|---|---|---|
| 폐기된 연구 버전이 더 관련성 높게 검색됨 | 현재 근거로 채택하지 않음 | 유효 버전과 차이 표시 |
| 두 문서의 수치가 충돌 | 하나를 임의 선택하지 않음 | 소유자 결정 요청 |
| 인용 뒤 원문이 변경됨 | 기존 초안·승인 무효화 | 영향 문장 재생성·재검토 |
| 저장 일부만 성공 | 완료 처리하지 않음 | 원장 대조 후 재시도 또는 수동 복구 |

## 8. 결과와 한계

결과물은 합성 근거 패킷, 문서·인용 계약, 사실·가정·충돌 표, 분야별 검토, 승인 초안과 복구 기록이다. 법률 품질, 제출 수리, 개발 속도나 준법 성과가 개선됐다고 주장하지 않는다.

## 9. 다음 결정

공개 실행 전에는 분야 전문가의 독립 인용 검사, 관할·템플릿 버전 평가, 기밀자료 격리와 전체 문서 철회·재승인 훈련을 통과해야 한다.
