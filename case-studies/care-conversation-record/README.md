# 사례: 상담·진료 대화에서 검토 가능한 기록과 위험 이관까지

## 현재 범위와 설계 목표

| 구분 | 외부 시스템 변경 범위 | 자율성 | 관련 P 단계 |
|---|---|---|---|
| 현재 공개 결과 | 외부 시스템 변경 없음 | A0 | 없음 |
| 설계 목표 | 초안 전용 | A1-A2 | P1, P2, P3 |

현재 값은 이 저장소에서 재현할 수 있는 범위만 나타낸다. 현재 결과의 P 표시는 해당 단계에 속한 기능이 구현됐다는 뜻이며, 그 단계의 통과 기준을 모두 충족했다는 뜻은 아니다. 설계 목표는 아직 구현 범위나 조직 운영 성과가 아니다.
<!-- case-boundary:end -->

현재 공개물은 설계 문서와 메타데이터다. 아래 문제·현재 흐름은 실습을 위한 가정이며 입력 세트, 실행 코드, 실행 로그와 검수 결과는 아직 공개하지 않았다. 목표 흐름·평가·결과물은 앞으로 구현하고 확인할 항목이다.

사례별 P 단계 표는 [프로젝트 공통 통과 기준](../../projects/README.md)에 더할 조건이다. P1의 최소 평가 수와 독립 검수를 생략하지 않으며, P4 계획이나 준비 문서만으로 운영 파일럿을 통과했다고 표시하지 않는다.

허구의 상담·진료 대화를 구조화된 기록 초안으로 바꾸고 위험 신호를 전문 인력에게 이관하는 고위험 시뮬레이션이다. 진단·치료·긴급 서비스를 제공하거나 전문가 서명 없이 공식 기록을 만들지 않는다.

## 현재 공개 결과와 근거

현재 근거는 `simulation-design` 문서다. [공개 사례-실습 연결표](../../research/public-case-application-map.md)의 K08은 위험 후보를 당직자에게 즉시 알리고 수신 여부를 확인하는 절차에, K09는 동의·민감 기록 통제에 반영했다. K10의 담당자 수정 방식과 G08의 임상 기록 승인은 전문가의 수정·거절·서명과 기록 시스템 반영 조건으로 사용했다. 실제 환자·돌봄 대상자 데이터는 사용하지 않았다.

## 1. 사례 성격

| 항목 | 내용 |
|---|---|
| 도메인·산업 | 데이터·운영 / 의료·복지 |
| 위험·설계 목표 자율성 | 높음 / A1–A2 |
| 설계 목표 연습 범위 | P1–P3, 기록·이관 초안 전용 |
| 합성 입력 | 동의 상태가 다른 허구 대화, 약물명 오인식, 자해·학대·응급 신호와 일상 상담 |

## 2. 문제와 책임

전문가는 대화에 집중하면서 기록을 남기고 긴급 위험을 놓치지 않아야 한다. 요약 누락이나 잘못된 화자·약물·증상은 안전에 직접 영향을 줄 수 있다. 전문가는 공식 기록을 확정하고, 별도의 당직·관제 책임자는 긴급 인계를 결정한 뒤 담당자 수신과 처리 상태를 확인한다.

## 3. 목표 흐름

```text
합성 동의 상태와 대화 수신
→ 녹음·처리 허용 범위 확인
→ 화자·시각·불명확 표현을 보존한 전사
→ 사실·관찰·당사자 진술을 구분한 기록 초안
→ 위험 신호는 일반 기록과 별도로 즉시 사람에게 알림
→ 전문가가 대화 원문과 비교해 수정·거절·서명
→ 승인된 기록만 기록 시스템 샌드박스에 저장
→ 이관 수신과 처리 상태 확인
```

## 4. 데이터와 통제

| 원본 | 필요한 상태 | 통제 |
|---|---|---|
| 동의 레지스트리 | 대상, 목적, 범위, 만료 | 유효 동의가 없으면 처리하지 않는다. |
| 대화 원문 | 화자, 시각, 불명확 구간 | 초안 문장마다 근거가 된 원문의 해당 구간을 표시한다. |
| 기록 시스템 | 템플릿, 기존 기록, 서명 상태 | AI 초안과 전문가 서명을 구분한다. |
| 이관 명부 | 당직자, 연락 수단, 수신 상태 | 알림 발송을 처리 완료로 보지 않는다. |

## 5. 승인·중단 경계

- AI는 전사, 구조화, 초안과 위험 후보만 만든다.
- 진단, 치료, 약물 변경, 위험 등급 확정과 공식 기록 서명은 전문가만 한다.
- 동의 부재, 대상 불일치, 화자 혼동, 중요 구간 전사 실패면 기록 생성을 중단한다.
- 자해·학대·응급 후보는 모델 답변을 기다리지 않고 정해진 당직자 인계 절차를 병행한다.
- 사람에게 알림이 도달하고 수신 확인이 있어야 이관 완료로 기록한다.

## 6. P1–P3와 평가

| 단계 | 실습 | 통과 기준 |
|---|---|---|
| P1 | 30개 이상의 허구 대화 전사·기록·위험 후보 | 중요한 사실마다 대화 원문의 근거 구간 표시, 동의 없는 처리 0건 |
| P2 | 전문가 수정·거절·서명과 긴급 이관 | 서명 없는 공식 기록 0건, 위험 인계 누락 0건 |
| P3 | 기록·이관 샌드박스 상태 대조 | 수신 확인, 중복 방지, 부분 실패 복구 |

단어 오류율과 함께 중요한 사실 누락, 화자 오류, 약물·수치 오류, 전문가 수정 시간, 잘못 울린 경보, 놓친 위험 신호, 인계 알림 도달·수신 시간을 본다.

### 중요한 맥락의 누락 평가

[G08의 보완 근거](../../research/public-ax-cases.md)에는 2026-06-29에 공개된 단일기관 학회 초록이 있다. 이 자료는 마지막 조사 뒤에 발생한 변화가 아니라 당시 빠져 있던 반례다. 작은 표본의 결과를 모든 모델의 임상 정확성으로 일반화하지 않는다.

합성 평가 세트에는 가족 관계, 상실 경험, 돌봄 여건처럼 요약에서 빠지면 전문가 판단이 달라질 수 있는 내용을 넣는다. 전문가가 원문과 초안을 대조해 중요한 사실의 누락, 잘못된 추가, 수정 시간을 기록한다. 처리 속도가 빨라져도 중요한 맥락이 빠지면 검수를 통과시키지 않는다. 실제 환자 자료 없이 이 절차를 연습할 수 있게 허구 대화를 사용한다.

## 7. 실패 주입과 복구

| 실패 | 기대 동작 | 복구 |
|---|---|---|
| 동의가 만료됨 | 전사·요약을 시작하지 않음 | 새 동의 확인 또는 수동 기록 |
| 약물명이 비슷한 단어로 전사됨 | 불확실성을 표시 | 전문가가 대화 원문의 해당 구간 확인 |
| 당직자 알림 실패 | 완료로 표시하지 않음 | 대체 연락망과 수동 전화 |
| 기록 저장만 실패 | 이관을 되돌리지 않음 | 부분 실패 원장 뒤 수동 기록 |

## 8. 결과와 한계

실습에서 만들 결과물은 허구 대화, 동의·기록 데이터 계약, 원문 연결 초안, 전문가 변경, 이관·수신과 복구 기록이다. 임상 결과, 안전, 돌봄 품질이나 시간 절감 근거는 없다.

## 9. 다음 결정

공개 실행 전에는 의료·돌봄 전문가와 개인정보·법무 검토자가 합성 평가 세트, 필수 이관 규칙, 보존·삭제와 수동 대체 절차를 승인해야 한다.
