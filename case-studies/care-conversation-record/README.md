# 사례: 상담·진료 대화에서 검토 가능한 기록과 위험 이관까지

<!-- case-boundary:start -->
## 현재 범위와 설계 목표

| 구분 | 쓰기 영향 | 자율성 | P 단계 |
|---|---|---|---|
| 현재 공개 실행물 | 외부 쓰기 없음 | A0 | 없음 |
| 설계 목표 | 초안 전용 | A1-A2 | P1, P2, P3 |

현재 값은 이 저장소에서 재현할 수 있는 범위만 나타낸다. 설계 목표는 아직 구현 범위나 조직 운영 성과가 아니다.
<!-- case-boundary:end -->

허구의 상담·진료 대화를 구조화된 기록 초안으로 바꾸고 위험 신호를 전문 인력에게 이관하는 고위험 시뮬레이션이다. 진단·치료·긴급 서비스를 제공하거나 전문가 서명 없이 공식 기록을 만들지 않는다.

## 현재 실행물과 근거

현재 근거는 `simulation-design` 문서다. [공개 사례 K08·K09·K10·G08](../../research/public-case-application-map.md)에서 위험 신호 인계, 민감 기록, 담당자 수정권과 임상 기록 승인이라는 질문을 가져왔다. 실제 환자·돌봄 대상자 데이터는 사용하지 않았다.

## 1. 사례 성격

| 항목 | 내용 |
|---|---|
| 도메인·산업 | 데이터·운영 / 의료·복지 |
| 위험·설계 목표 자율성 | 높음 / A1–A2 |
| 설계 목표 연습 범위 | P1–P3, 기록·이관 초안 전용 |
| 합성 입력 | 동의 상태가 다른 허구 대화, 약물명 오인식, 자해·학대·응급 신호와 일상 상담 |

## 2. 문제와 책임

전문가는 대화에 집중하면서 기록을 남기고 긴급 위험을 놓치지 않아야 한다. 요약 누락이나 잘못된 화자·약물·증상은 안전에 직접 영향을 줄 수 있다. 전문가가 공식 기록을 확정하고, 별도의 당직·관제 책임자가 긴급 이관을 소유한다.

## 3. 목표 흐름

```text
합성 동의 상태와 대화 수신
→ 녹음·처리 허용 범위 확인
→ 화자·시각·불명확 표현을 보존한 전사
→ 사실·관찰·당사자 진술을 구분한 기록 초안
→ 위험 신호는 일반 기록과 별도로 즉시 사람에게 알림
→ 전문가가 원대화와 비교해 수정·거절·서명
→ 승인된 기록만 기록 시스템 샌드박스에 저장
→ 이관 수신과 처리 상태 확인
```

## 4. 데이터와 통제

| 원본 | 필요한 상태 | 통제 |
|---|---|---|
| 동의 레지스트리 | 대상, 목적, 범위, 만료 | 유효 동의가 없으면 처리하지 않는다. |
| 원대화 | 화자, 시각, 불명확 구간 | 초안 문장을 원구간과 연결한다. |
| 기록 시스템 | 템플릿, 기존 기록, 서명 상태 | AI 초안과 전문가 서명을 구분한다. |
| 이관 명부 | 당직자, 연락 수단, 수신 상태 | 알림 발송을 처리 완료로 보지 않는다. |

## 5. 승인·중단 경계

- AI는 전사, 구조화, 초안과 위험 후보만 만든다.
- 진단, 치료, 약물 변경, 위험 등급 확정과 공식 기록 서명은 전문가만 한다.
- 동의 부재, 대상 불일치, 화자 혼동, 중요 구간 전사 실패면 기록 생성을 중단한다.
- 자해·학대·응급 후보는 모델 답변을 기다리지 않고 정해진 사람 이관 절차를 병행한다.
- 사람에게 알림이 도달하고 수신 확인이 있어야 이관 완료로 기록한다.

## 6. P1–P3와 평가

| 단계 | 실습 | 통과 기준 |
|---|---|---|
| P1 | 30개 이상의 허구 대화 전사·기록·위험 후보 | 중요한 사실 원구간 연결, 동의 없는 처리 0건 |
| P2 | 전문가 수정·거절·서명과 긴급 이관 | 서명 없는 공식 기록 0건, 위험 인계 누락 0건 |
| P3 | 기록·이관 샌드박스 상태 대조 | 수신 확인, 중복 방지, 부분 실패 복구 |

단어 오류율보다 중요한 사실 누락, 화자 오류, 약물·수치 오류, 전문가 수정 시간, 거짓·누락 경보, 이관 도달·수신 시간을 본다.

## 7. 실패 주입과 복구

| 실패 | 기대 동작 | 복구 |
|---|---|---|
| 동의가 만료됨 | 전사·요약을 시작하지 않음 | 새 동의 확인 또는 수동 기록 |
| 약물명이 비슷한 단어로 전사됨 | 불확실성을 표시 | 전문가가 원구간 확인 |
| 당직자 알림 실패 | 완료로 표시하지 않음 | 대체 연락망과 수동 전화 |
| 기록 저장만 실패 | 이관을 되돌리지 않음 | 부분 실패 원장 뒤 수동 기록 |

## 8. 결과와 한계

결과물은 허구 대화, 동의·기록 데이터 계약, 원문 연결 초안, 전문가 변경, 이관·수신과 복구 기록이다. 임상 결과, 안전, 돌봄 품질이나 시간 절감 근거는 없다.

## 9. 다음 결정

공개 실행 전에는 의료·돌봄 전문가와 개인정보·법무 검토자가 합성 평가 세트, 필수 이관 규칙, 보존·삭제와 수동 대체 절차를 승인해야 한다.
