# 사례: 기업 자료에서 여신·인수심사 검토 초안까지

| 구분 | 쓰기 영향 | 자율성 | P 단계 |
|---|---|---|---|
| 현재 공개 실행물 | 외부 쓰기 없음 | A0 | 없음 |

합성 기업의 재무제표, 신청서, 거래·담보 자료와 심사 규칙을 연결해 검토 초안을 만드는 고위험 시뮬레이션이다. AI는 승인·거절, 한도, 가격이나 보험 인수 결정을 내리지 않는다.

## 현재 실행물과 근거

현재 근거는 `simulation-design` 문서다. [공개 사례 K02·K03·G11](../../research/public-case-application-map.md)에서 재무·산업 자료 통합, 생성형 추천과 결정론적 규칙의 분리, OCR과 심사자 승인이라는 질문을 가져왔다. 실제 고객·보험사·은행 데이터는 사용하지 않았다.

## 1. 사례 성격

| 항목 | 내용 |
|---|---|
| 도메인·산업 | 재무·구매 / 금융서비스 |
| 위험·설계 목표 자율성 | 높음 / A1–A2 |
| 설계 목표 연습 범위 | P1–P3, 검토 초안 전용 |
| 합성 입력 | 제조업·서비스업 기업 12곳의 신청서, 재무제표, 담보, 누락·불일치 문서 |

## 2. 문제와 책임

심사자는 여러 문서와 수치를 맞추고 상품·산업 규칙을 적용해 확인 질문과 의견을 작성한다. OCR 오류나 오래된 규칙을 사실처럼 쓰면 차별적이거나 설명할 수 없는 판단으로 이어질 수 있다. 심사자만 최종 결정을 내리며 정책 소유자가 규칙 버전을 책임진다.

## 3. 목표 흐름

```text
합성 신청 패키지 수신
→ 문서·기업·기간 식별과 OCR 품질 검사
→ 재무 원본 수치 대조
→ 적용 상품·산업 규칙 버전 결정
→ 사실, 규칙 결과, 가정을 분리한 검토 초안
→ 누락 자료와 확인 질문 제안
→ 심사자가 수정·거절·확정
→ 초안과 근거만 심사 샌드박스에 기록
```

## 4. 데이터와 통제

| 원본 | 필요한 상태 | 통제 |
|---|---|---|
| 문서 저장소 | 원문, 페이지, OCR 신뢰도, 제출 시각 | 숫자는 원문 페이지와 연결한다. |
| 재무 스냅샷 | 기간, 단위, 연결·별도 구분 | 단위·기간이 다르면 계산을 중단한다. |
| 규칙 레지스트리 | 상품, 산업, 시행일, 예외 | 모델이 규칙을 생성하거나 우회하지 못한다. |
| 검토 원장 | 사실·규칙·가정, 수정, 승인자 | 추천과 실제 결정 기록을 분리한다. |

## 5. 승인·중단 경계

- AI는 자료 추출, 비율 계산, 규칙 실행 결과와 확인 질문만 제안한다.
- 보호 특성의 대리변수, 설명할 수 없는 점수나 학습 데이터 추정은 사용하지 않는다.
- 문서 누락, 수치 불일치, 규칙 버전 부재, OCR 임계값 미달이면 의견을 완성하지 않는다.
- 승인·거절, 가격, 한도, 상품 제안과 고객 통지는 심사자와 기존 결정 시스템의 책임이다.

## 6. P1–P3와 평가

| 단계 | 실습 | 통과 기준 |
|---|---|---|
| P1 | 합성 문서 추출, 수치 대조와 규칙 실행 | 숫자별 원문 연결, 단위 오류·누락 거절, 규칙 재현 가능 |
| P2 | 심사자의 수정·보류·거절 | 최종 결정 자동화 0건, 사실·가정 혼합 0건 |
| P3 | 검토 초안을 샌드박스에 기록 | 승인 전 쓰기 차단, 버전과 멱등 키 확인 |

문서 추출 정확도뿐 아니라 숫자 출처, 잘못 적용한 규칙, 심사자 수정량, 불확실성 거절, 집단별 오류 차이와 감사 재현성을 측정한다.

## 7. 실패 주입과 복구

| 실패 | 기대 동작 | 복구 |
|---|---|---|
| 천원·원 단위 혼합 | 계산과 초안 중단 | 원문 단위 확인 후 재실행 |
| 전년도 규칙 검색 | 현재 결정에 적용하지 않음 | 시행일이 맞는 버전 지정 |
| 서명이 빠진 문서 | 완전한 패키지로 표시하지 않음 | 추가 자료 요청 큐 생성 |
| 승인 뒤 초안 변경 | 기존 승인 무효화 | 새 버전 재검토 |

## 8. 결과와 한계

결과물은 합성 신청 패키지, 문서·수치 계약, 규칙 실행 기록, 검토 초안, 심사자 변경과 감사 기록이다. 승인 품질, 손실률, 전환율이나 처리 시간이 개선됐다는 근거는 없다.

## 9. 다음 결정

공개 실행 전에는 합성 정답 세트, 계산 재현 시험, 편향·대리변수 검토와 독립 심사자 평가가 필요하다. 실제 적용은 법무·준법·모델 위험관리 승인을 별도로 받아야 한다.
